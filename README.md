# Лабораторная работа №2 — Курсы валют

## Описание

Консольное приложение на языке Python для выполнения валютных операций.

Программа разработана с использованием объектно-ориентированного программирования, модульной архитектуры и базы данных SQLite.

**Уровень сложности:** Well-done.

## Функциональные возможности

- Работа с семью валютами: RUB, USD, EUR, GBP, CNY, JPY, CHF.
- Расчёт обменного курса между выбранными валютами.
- Конвертация денежных сумм.
- Расчёт комиссии за валютные операции.
- Расчёт простых процентов по банковскому счёту.
- Автоматическое сохранение результатов в SQLite.
- Экспорт результатов в документ Word (.docx).
- Запуск приложения в Docker.

Курсы валют фиксированы и используются исключительно для демонстрационных расчётов. Приложение не выполняет реальные банковские переводы.

## Используемые технологии

- Python 3.9+ (в Docker используется Python 3.12)
- ООП: абстрактные классы, наследование, свойства и специальные методы
- SQLite3 — база данных
- python-docx — создание Word-документов
- pytest — автоматизированное тестирование
- Docker — контейнеризация приложения

## Структура проекта

- `main.py` — консольный интерфейс и точка входа.
- `currency_package/models.py` — классы Currency, Account, Transaction и FinancialEntity.
- `currency_package/calculations.py` — расчёт валютных операций и процентов.
- `currency_package/reports.py` — формирование Word-отчётов.
- `database.py` — создание таблиц и сохранение результатов в SQLite.
- `test/` — автоматизированные тесты.
- `Dockerfile` — инструкция по сборке Docker-образа.
- `requirements.txt` — зависимости Python.

## Запуск через Python

Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

Запустить приложение:

```bash
python main.py
```

## Консольное меню

После запуска пользователю доступны команды:

1. Конвертация валют.
2. Расчёт процентов по счёту.
3. Сохранение результатов в Word.
0. Завершение программы.

Для выполнения операции необходимо выбрать соответствующий пункт и ввести требуемые параметры.

## Запуск через Docker

Собрать образ:

```bash
docker build -t python-lab-2 .
```

Создать папку `data` в корне проекта.

Запустить контейнер из PowerShell:

```powershell
docker run --rm -it -v "${PWD}/data:/app/data" python-lab-2
```

Результаты вычислений сохраняются в SQLite-файле `data/currency_lab.db`.

Word-отчёты также сохраняются в папке `data`.

## База данных

SQLite используется для постоянного хранения результатов расчётов.

База содержит две основные таблицы:

- `conversions` — сведения о конвертациях валют, обменных курсах и комиссиях.
- `interest_calculations` — результаты начисления процентов по счетам.

Таблицы создаются автоматически при первом запуске программы.

## Тестирование

Для тестирования используется pytest.

Запуск тестов локально:

```bash
python -m pytest -v
```

Запуск тестов внутри Docker:

```bash
docker run --rm python-lab-2 python -m pytest -v
```

Реализовано 26 автоматизированных проверок, охватывающих классы, вычисления, обработку ошибок и работу SQLite.

## Особенности реализации

Программа имеет модульную структуру. Финансовые сущности представлены классами, вычисления отделены от хранения данных, а единый консольный интерфейс используется как при локальном запуске, так и внутри Docker.

Приложение является учебным MVP-проектом и не предназначено для выполнения реальных банковских операций.
