# Лабораторная работа №2 — Курсы валют

## Описание проекта

Приложение для расчёта валютных курсов, комиссий и процентов по банковским счетам.

Проект разработан на языке Python с использованием объектно-ориентированного программирования (ООП) и модульной структуры.

## Текущий функционал

- Конвертация валют RUB, USD и EUR.
- Использование фиксированных курсов валют.
- Расчёт комиссии за валютные операции.
- Расчёт простых процентов по банковскому счёту.
- Графический интерфейс на tkinter.
- Экспорт результатов расчётов в документ Word.

## Используемые технологии

- Python 3.12+
- tkinter — графический интерфейс
- python-docx — создание документов Word

## Структура проекта

- `main.py` — графический интерфейс и точка входа в приложение.
- `currency_package/models.py` — классы Currency, Account и Transaction.
- `currency_package/calculations.py` — классы для финансовых расчётов.
- `currency_package/reports.py` — экспорт результатов в Word.
- `requirements.txt` — зависимости проекта.

## Инструкция по запуску

1. Установить Python 3.12 или новее.
2. Открыть папку проекта `python-lab-2` в PyCharm.
3. Создать и активировать виртуальное окружение Python, если оно ещё не настроено.
4. Установить зависимости командой `python -m pip install -r requirements.txt`.
5. Запустить программу командой `python main.py`.

## Краткая справка

### Конвертация валют

Выберите исходную и целевую валюты, введите сумму и процент комиссии. Нажмите кнопку **«Конвертировать»**.

Программа рассчитает сумму обмена, комиссию и итоговую сумму к получению.

Используются условные фиксированные курсы:

- 1 RUB = 1 RUB
- 1 USD = 90 RUB
- 1 EUR = 100 RUB

### Расчёт процентов

Введите баланс счёта, годовую процентную ставку и количество дней. Нажмите кнопку **«Рассчитать проценты»**.

Программа рассчитает сумму начисленных простых процентов по счёту.

Валюта счёта соответствует исходной валюте, выбранной в блоке конвертации.

### Экспорт результатов

После выполнения расчётов нажмите кнопку **«Сохранить отчёт в Word»** и выберите место сохранения документа.

Программа создаст файл `.docx` с результатами последних выполненных расчётов.

## Тестирование

Для автоматизированного тестирования приложения используется библиотека pytest.

Тесты располагаются в папке `tests` и проверяют:

- Создание объектов Currency, Account и Transaction.
- Корректность валютных курсов.
- Работу managed-атрибутов.
- Обработку некорректных входных данных.
- Расчёт конвертации и комиссий.
- Начисление процентов.
- Абстрактные классы и наследование.
- Специальные методы классов.

Для запуска тестов необходимо выполнить команду:

`python -m pytest -v`

Тестирование выполняется без запуска графического интерфейса.

## База данных SQLite

Для постоянного хранения результатов вычислений используется SQLite.

База данных автоматически создаётся при первом запуске приложения и сохраняется в файле `currency_lab.db`.

База содержит две таблицы:

- `conversions` — история конвертаций валют, включая обменные курсы, суммы и комиссии.
- `interest_calculations` — история расчётов процентов по счетам.

После выполнения расчёта данные автоматически сохраняются в соответствующую таблицу.

Для проверки работы базы данных используются автоматизированные тесты `pytest`. Тестирование выполняется с использованием временных баз данных и не изменяет основную базу приложения.
